Rallybox User Manual

Rallybox is a rally meter for classic-car regularity rallies. It measures the distance the car has travelled, compares it with the schedule the crew have entered, and tells the driver how many seconds ahead of or behind that schedule the car is.

The box has two screens. The co-pilot screen, on the left, is where the navigator sets the stage up and works the controls. The driver screen, on the right, shows a gauge and nothing the driver has to operate. A phone on the same network can show the same readings and work most of the same controls.

This manual describes the box first and the phone app second.

Part 1 — The box

date/time

Setting Rally Clock

The System Clock is the Raspberry Pi's own clock. The Rally Clock is the one every stage is timed against. Set Rally Clk is used to update the Rally Clock and is prepopulated ready for editing.

  1. Tap the date box and delete what is there with <-.
  2. Type the date on the keypad as yyyy/mm/dd, using the / key for the separators.
  3. Tap the time box, delete what is there, and type the time as hh:mm:ss, using the : key.
  4. Press Save new rally clock entry.

IMPORTANT: Both date and time boxes must be complete and formatted correctly otherwise the changes will not be saved.

Trimming the Rally Clock

The time you type becomes true at the instant you press the button, so whatever fraction of a second you were late by stays in the Rally Clock for the rest of the rally. The -0.1 and +0.1 buttons under the time box correct it, a tenth of a second per press: +0.1 makes the Rally Clock read later, -0.1 earlier. Hold a button down to repeat, about a second and a half for a whole second of adjustment.

The Rally Clock shows a tenths digit so you can see the trim take effect. The System Clock stays at whole seconds, and the two are not tied together — the Rally Clock is free to change its second at any point, which is what lets it hold an offset that is not a whole number of seconds.

Each press is saved immediately. The Save new rally clock entry button is not involved, and does not need to be pressed afterwards.

Force Single Display

This switch puts everything on the co-pilot screen, with a small driver gauge in the right-hand panel, for use where only one display is fitted. It is saved as soon as it is switched, and takes effect the next time the box is started.

Speed units

The button shows the unit in use. Pressing it switches between KPH and MPH, and every speed on every screen, and on the phone, changes with it. It is saved as soon as it is pressed.

Phone Control Link

The address and QR code show where to reach the phone app. Point a phone camera at the code, or type the address into a phone browser. The phone must be on the same network as the box. Part 2 describes what the phone can do.

Exit App

exit app saves the settings and closes the program. It does not switch the Raspberry Pi off.
