Programming, Starting, Navigating

Getting around

Every page has a menu key at the bottom right. Press it to reach the main menu.

  • navigation – used while navigating and on stages.
  • segments – stage setup.
  • date / time – set rally time.
  • calibration – set pulses per kilometre.
  • settings – beep, tone, rally type, units and logging; the spanner key opens the Setup sub menu (displays, Bluetooth speaker, Wi-Fi and the phone link, software updates).
  • exit – saves the settings and closes the program. It does not switch the Raspberry Pi off.

Numbers are typed on the on-screen keypad: C clears a selected entry and the arrow key deletes one character. There is no Enter key: an entry is saved automatically when you tap another box or after no activity for a second.

Greek rally type

Characteristics of greek rallies

  • Stages start at roadbook boxes.
  • Distance is zeroed at each stage start.
  • Departure is at a set minute.
  • Speeds change at roadbook boxes.

Programming Greek Stages

Select greek rally type from the settings page and then select segments from the main menu.
The segments page will display a Greek flag.
The system defaults to metres but can be set to KM in settings.

Entering Greek stage data

When entering stage data you can choose to enter every roadbook box in the stage, or only those rows with speed changes. With every box entered, Beep Assist navigation (when on) beeps ahead of each box.

  1. Select the stage with − n +, or tap the number (1–99).
  2. Tap the box beside add distance and type the cumulative distance at which each row ends, separated by semicolons: 540;1320;2010 (or 0.54;1.32;2.01 in km). Later entries are appended or inserted as needed. Distances are separated by a semicolon only: a comma is refused with a warning, and in metres a decimal point is refused too (whole metres only). The add distance key shows the unit in use on its second line, and the grey example in the box follows it.
  3. Press add distance and the distances will be added to the summary table.
  4. For rows with speed changes tick chg and enter the speed.
  5. A new speed change comes with auto already ticked, so the box changes speed automatically at the specified distance. Untick it if the navigator will press next speed on the navigation page. The first row has no auto tick.
  6. Start time – enter when the stage starts (hh:mm:ss).
  7. Distance at start – enter the roadbook distance at the start line. (If entered the box will show the speed and time needed to arrive at the next stage on time.
  8. Autostart – tick to arm an autostart at today's start time (a past time is refused). It can also be armed/disarmed on the navigation page.

Entries save automatically under the stage number shown. A running stage cannot be edited.

The roadbook ends you type are kept as typed. Setting the start figure (from) afterwards only shortens or lengthens the first row; it does not move the other ends, and typing the first end never wipes a start already set. A start that is not before the first end is refused.

Uploading stages
upload stage on the phone's Segment page opens a window showing the CSV columns required for greek, surrey and italian rallies. Choose the CSV, or paste it into the box, then press check and load. If a stage is already programmed it asks for confirmation before it is replaced. The same key on the box opens a file window and loads that file. It is greyed while a stage is running. In the CSV, units is m, km or miles – the unit of every distance in the file. auto y on a row with a new speed changes to that speed by itself when the row starts; a blank waits for next speed. Once a file is loaded the Segments page shows the first stage loaded.

Clearing stages

clear stage empties the stage shown; clear all empties every stage. Both ask for confirmation first.

Starting a Greek Stage

A stage can be started via preprogrammed autostart (using the time programmed on the Segments page), or by pressing the Start Now or Start On Next Minute buttons.

Autostart: When autostart is armed the button will appear as black on white, and the word auto (cyan) appears next to the start time. When Autostart is not armed the word manual (orange) appears. A start time that has passed, with nothing armed or running, is crossed out in red. Autostart can be toggled on/off using the Autostart button on the navigation display.

What happens with autostart:

  • With less than 5 minutes to the start the driver's display will show a countdown clock, with Early Departure DISABLED beside it.
  • The Total and Trip distances will zero at the start time.
  • The timer resets at the start time.

Start on Next Minute: The Start on Next Minute button constantly updates to show the next whole minute. Pressing it sets a type of autostart at that minute.

What happens with Start on Next Minute:

  • Pressing the button automatically overrides any programmed autostart.
  • The Total and Trip distances zero immediately (not at the departure minute). Any distance driven between pressing and the start minute will be included in the stage distance.
  • The timer resets at the start minute.
  • The driver's display shows a countdown clock with Early Departure ENABLED beside it: the distance is already counting, and only the clock waits for the start minute.

Start Now: Pressing it starts a stage immediately.

What happens with Start Now:

  • Pressing the button overrides a programmed autostart.
  • The Total and Trip distances zero immediately.
  • The timer resets immediately.
  • On a Greek stage the Trip history clears. Italian and Surrey keep it.

Starting scenarios

Regular on-schedule start – in most instances this will be handled correctly by a pre-programmed autostart which resets the distances and timer at the allotted start time.

Late arrival at start – there are 2 ways to handle this scenario.

  • Have autostart start the stage on time (before you have arrived) and press Total to zero the distances at the start line and attempt to catch up during the stage. This is the preferred method.
  • Press Start Now at the line if a stage is not running on the box. Because the timer will have started late the driver will need to catch up and target a reading where the seconds ahead is equal to the delay in starting.

Obstructed start – if traffic or road conditions may make you late to the first timing point, press the next-minute start key (flag with a time) on the start line instead of using autostart, and move off shortly before departure. Total and Trip reset when pressed; timing starts at the minute.

Navigating a Greek Stage

total

The total button controls the Distance and elapsed time since the start. Press to zero the distance.

  • Outside a stage: pressing zeroes the distance and timer, not Trip.
  • Waiting for a timed autostart: pressing zeroes Total, Trip and the timer without asking; the autostart zeroes them again at its start time. (An autostart cannot be armed during a stage.)
  • If Start on Next Minute has been selected: pressing zeroes Total and Trip without asking; the timer starts at the minute.
  • During a stage (such as after a missed start) pressing to reset the total requires confirmation, but then zeroes Total and Trip from the time of the first press; the stage clock keeps running. The stage goes back to its first row, then moves forward only by the distance driven while the confirmation was open. This applies to greek; during an italian sector or a surrey stage the total cannot be reset (see the italian total key and the surrey section).

trip

Shows intermediate distance and time. Press to zero it. Prior figures appear in the Trip history column. Trip also restarts at every speed change, and at every roadbook box that carries on at the same speed. The cyan sub average on the driver display does not restart at those same-speed boxes; it restarts only at a speed change. Starting a Greek stage clears the trip.

countdown

The distance and time to the next speed change are displayed next to the button. The button cannot be pressed. When there is no later speed change, the distance counts down to the finish and the time is left blank.

next speed and prev speed

next speed is used to move to the next programmed speed manually. The current speed is displayed in white in the stage panel. prev speed undoes the last speed change and the box recalculates the data as if the speed change had not taken place. Pressed late, even after the roadbook point, it still puts the earlier speed back and the box waits for next speed again. Both buttons override previous manual and automated speed changes.

+10, set and −10

+10 / -10 increment all the distance counters 10 m per press (0.01 mile per press, shown as +.01 / -.01, when Distance units is miles); -10 cannot take a counter below zero; set allows a precise distance to be entered for Total (and Trip remains unchanged). During a stage, corrections apply across average speeds and timing errors.

freeze and reverse

Pressing freeze stops the distances from incrementing; pressing freeze again starts the distance incrementing from the frozen figures. Clocks and timers continue to increment while frozen – use it after a navigation error.

reverse makes Total and Trip (as well as countdown) increment backwards. It is typically used when reversing after overshooting a junction as the box cannot determine the direction of travel. With reverse pressed the distances can become negative.

Freeze overrules Reverse if both are pressed. The buttons display as black on white when active and a whooping sound is emitted.

A-B, B-C zero

Where a rally is measured on an AB, BC basis and this option has been selected in settings, the A-B, B-C zero button appears under the Trip history in the navigation window. Pressing this during a stage when a timing mark or timing marshal is seen sets the timing error in the driver's display to zero and the average speed calculation is made independently between each timing mark.

The popup shows the current error size to be removed and the adjustment already applied.

  • Yes zeroes the needle at this instant.
  • Reset to 0.0 removes the adjustment so the true error shows.
  • No does not make and changes and returns the box to the navigation screen.

The stage panel display

The stage panel shows the selected stage, the start time of the stage and autostart status, the distances at which speed changes commence (the current segment is shown in white) and the speed needed (and allotted time) to reach the next stage with 1 minute to spare.

Italian rally type

Characteristics of italian rallies

  • A stage covers an entire sector from one time control (CO) to the next.
  • A sector is made up of substages involving:
    • untimed driving
    • timed trials (pc)
    • average trials (pm)
    • stamp checks (ct)
    • the closing time control (co)
  • Sectors start and finish on specific minutes but the intervening substages do not have to start at a specific time.
  • Total distance is not zeroed at the start.

Italian rallies have many short back-to-back timed trials without a pause between them so each time-control section is programmed as linked substages.

The substage types:

TypeWhat it isHow the box treats it
navi (grey)Untimed driving between controls.A suggested speed is worked out from the sector's total duration on order that the car arrives at the final time control in the correct mminute
pc (red, stopwatch)A imed trial between two pressure tubes. Speed is worked out from the subsector's duration (not distance).
pm (yellow)An average speed check with unknown timing points.Duration is worked out from the given speed (not the elapsed time).
ct (blue)A substage ending with a Stamp check Untimed, like navi.
co (green)A substage that ends with a time control ending the sector; scheduled arrival within a minute.This the last row of the sector. The arrival time is worked out from the card.

Programming Italian Sectors

Select italian rally from the settings page and then select segments from the main menu. The segments page will display an Italian flag. Choosing the italian rally type does not change the distance units: for Italian sectors set Distance units to km (two decimals) in settings.

Entering Italian sector data

Enter every substage on the organiser's Times and Distance Table (TDT) starting from the row after the opening time control, up to and including the closing time control (here co 2). The opening time control (co) line is not entered where it has zero distance (0.00 km).

  1. Select the sector with − n +, or tap the number (1–99): the number of its starting time control.
  2. Tap the box beside add distance and enter the cumulative distances (progr) at which each substage ends either one at a time or enter several separated by semicolons. (eg 1.20;1.38;1.44;6.80;9.20;15.60;18.40 (or 1200;1380;1440;6800;9200;15600;18400 in metres)). Subsequent entries are appended or inserted as needed; take care when inserting a distance inside an existing pc or pm which will get recalculated.
  3. Press add distance.
  4. Tap the type tag to cycle to the correct type for each row (navi → pc → ct → pm → co). Each new row for a pc, pm, ct or co substage gets allocated an incremental reference number in the row column but this can be overridden if incorrect.
  5. For pc rows enter the card's time (m:ss) in dur; the speed is worked out.
  6. For pm rows enter the speed in the KPH/MPH column; the duration is worked out.
  7. Start time – enter the departure minute at the opening co (hh:mm:ss).
  8. Duration – enter the card's sector duration (h:mm:ss). The Average displayed faintly below should correspond to that given on the TDT sheet.

Figures which can be edited are displayed in dark boxes; figures which are calculated and cannot be edited have grey boxes in the segments table. Entries are saved automatically. A running sector cannot be edited.

upload stage on the phone's Seg page opens a window. It shows the CSV columns required for greek, surrey and italian stage types, and marks the one this box is using. Choose the CSV, (or paste it into the box if using the phone app), then press check and load. A stage that is already programmed asks before it is replaced. The button is greyed while a stage is running.

Clearing sectors

clear stage empties the sector shown; clear all empties every sector. Both ask for confirmation first.

Starting an Italian Sector

A sector is started at the time control by pressing the start now button during the departure minute. The sector clock starts at the second you press, and the arrival target becomes that same second plus the card's sector duration. Sector total and sub distances zero; navi distance does not zero automatically. The stage now key reads stage abort when a sector is in progress. The box will start in the first substage.

Starting a new substage

  • Press next substage to enter the following substage (pc, pm etc). NB that this sets the sector total distance counter to the total distance on the card's progr entry. The navi distance increments independently – any variation will give a guide to calibration errors as long as Navi is not reset.
  • If next substage is pressed early or by mistake press prev substage to undo it.

At the final substage.
On arrival at the final time control (co) pressing next substage will end the sector. It will warn and ask for confirmation and if confirmed will end the sector and increment the sector selector to the next sector.

Navigating an Italian Sector

sector total

Distance and elapsed time in the sector, matching the card's progr value. Press to zero it outside a sector.

  • Outside a sector, it zeroes the distance and the timer but not sub.
  • During a sector the key does not reset: the box shows Use set or next during a sector and changes nothing. Sector total is zeroed by the start, and every next pins it to the card's figure; correct it by hand with set, and take back a wrong press with prev. The phone behaves the same.

sub

Distance in the current substage; zeroes at every new substage when next substage is pressed. Press to zero; inside a pc or pm it asks first (In stage / Reset sub now?, with RESET SUB or Back), as sector total does. The phone asks too.

navi

An independent distance counter, shown in cyan. Press to change the distance. A popup offers the option to reset or specify the distance.

next substage and prev substage

next substage is pressed to move to the next substage. prev substage undoes the change.

+10, set and −10

+10 / -10 increment all the distance counters (sector total, sub and navi) 10 m per press; -10 cannot take a counter below zero; set allows a precise distance to be entered for sector total.

freeze and reverse

Pressing freeze stops the distances from incrementing; pressing freeze again starts the distance incrementing from the frozen figures. Clocks and timers continue to increment while frozen – use it after a navigation error.

reverse makes Total and Trip (as well as countdown) increment backwards. It is typically used when reversing after overshooting a junction as the box cannot determine the direction of travel. With reverse pressed the distances can become negative.

Freeze overrules Reverse if both are pressed. The buttons display as black on white when active and a whooping sound is emitted.

The substage display

The count down time to the end of the substage is displayed in large white characters. Past the end of a substage, the count down distance (for example +0.04) and seconds (for example +0:01.4) turn red and count upwards.

Characteristics of surrey rallies

  • Stages start at a position (landmark) within a specific roadbook box.
  • The exact starting distance may be unspecified.
  • Total distance is not zeroed at the start.
  • Scored on time taken.

Programming Surrey Stages

Select surrey rally type from the settings page and then select segments from the main menu.
The segments page will display a Union Jack.
The page is otherwise the same as in Programming Greek Stages.

Entering Surrey stage data

Stage data is entered in the same way as for greek, with the following differences.

  • Start time – this is usually left blank.
  • The exact distance of the stage start is unknown. Enter the distance at the start of that roadbook box instead.
  • The exact distance of the stage end may also be unknown. Enter the distance at the end of that roadbook box instead.

upload stage, clear stage and clear all work in the same way as for greek.

Starting a Surrey Stage

A surrey stage is started by pressing the Start Now button as the car passes the start landmark. Autostart still works if a start time has been entered on the Segments page.

Before the start: Total must show the roadbook distance.

  • Between stages, press total to zero it where the roadbook restarts (box 1, box 66).
  • Always use set to enter the roadbook's figure at the start box.

What happens with Start Now:

  • The stage clock and the stage distance start from zero.
  • The Total distance is not zeroed and carries on counting.
  • The first row is cut short so that it ends at its roadbook box. Later speed changes then keep to the roadbook distances.

Navigating a Surrey Stage

total

The total button shows the roadbook's running distance.

  • Outside a stage: pressing zeroes the distance.
  • During a stage: the total cannot be reset. If pressed, the box shows Use set during a stage.

trip

Shows intermediate distance and time, as in greek. The last four figures appear in the Trip history column.

stage

Shows the distance since Start Now was pressed, in cyan. It shows dashes when no stage is on the gauge. It cannot be set.

countdown

During a stage the distance and time to the next speed change (or to the finish) are displayed at the foot of the stage column. Between stages, Stage arrival is shown there instead. Each figure sits above its legend.

set

set allows the roadbook's figure to be entered for Total. Use it at any roadbook box where Total has drifted. During a stage, set moves Total and the stage distance together.

next speed and prev speed

Speed changes happen automatically at each roadbook box. next speed and prev speed work in the same way as for greek.

Finishing a stage

A Surrey stage ends only when next speed is pressed on the last row (the finish landmark) or the stage is aborted; it never ends on distance. The stage ends and the time taken is displayed under the Trip history and on the phone. It is shown as s2 result (the stage number in place of 2), and stays until the next stage finishes.

Phone, beeps and A-B, B-C zero

  • The phone shows the same three figures and the time taken.
  • Beeps follow Total, counted from the start box.
  • A-B, B-C zero is available in the same way as for greek.

Driver displays

Greek and Surrey driver display

The driver display has two designs in Greek/Surrey mode - one for navigation and one in a stage.

Navigation (between stages)

With no stage running there is no needle. The top left shows the arrival speed: the speed needed to reach the next stage with a minute to spare. The distances and averages are Trip and Total.

In a stage

The stage display differs where marked.

During a timed stage the needle shows how far ahead/behind the driver is in seconds. If the error exceeds the current gauge scale (changeable from 1–3 seconds in settings) the needle will stay pinned far left (or far right if ahead) and the scale will expand. The red logo shows the stage number (S1, S2 …). The cyan sub average is your average speed since the last speed change. It restarts at each speed change, so it corresponds with the time error; the white average is the average since the total counter started.

The chevron

The chevron slides up the needle to visually represent the impending end to the current programmed segment row which has been programmed (and may include navigations, speed changes and the finish line). At the start of each row it sits 20% of the way up the needle; as the row is driven it slides up toward the horizontal row end line, arriving as the row ends. It moves with the row's scheduled time, not the distance driven, so a car that is early or late will reach the end of the row before or after the chevron reaches the line.

Autostart warnings

While an autostart is pending, a T- hh:mm:ss countdown shows mid-display with Early Departure ENABLED or DISABLED beneath, depending on whether a regular autostart or a start on next minute is triggered.

Italian driver display

The driver display has two designs in Italian mode - one for untimed/navigation substages and one for timed (pc & pm) substages.

Navigation (navi, ct and co rows)

The display is similar to those for greek/surrey rallies except the right-hand box shows the minutes in hand to the control arrival minutes: green when ahead, red when behind.

The substage time shows the time still left in the substage. Once past the line it counts up, with a leading +. There is no needle or chevron on these rows.

In a pc or pm

The chevron

Due to the short nature of many timed stages, and the increased timing accuracy in Italian stages, the chevron only moves in the last 5 seconds of the stage to visually count down to the end.

Single-display mode

With Force single display switched on, the driver's gauge shares the co-pilot screen. The keys work in the same way as on the navigation page.

  • Left: Total, Trip and countdown (or navi). Beside them are set, +10 and -10, in that order.
  • Along the foot: next speed, prev speed, freeze and reverse.
  • Middle: the rally clock and the − 1 + stage selector, above the gauge.
  • Right: the three flag keys and menu.

There is no A-B, B-C zero key in single-display mode, and no Trip history or stage table. Other pages are reached through menu. When a start is pending its countdown is shown over the gauge.

The phone app

The phone app works within a phone browser window if the box and phone are on the same network. The box or a phone can be set as the hub. The advantage of using the box as the hub is that multiple devices can be used as displays and it has proven reliable in testing. The disadvantage is that connected phones lose their network connection. The advantage of using the phone as the hub is that it can continue to synch its clock and receive messages, however, multiple wireless screens cannot be attached and when using an iPhone the system will not reconnect automatically if the phone ever loses reception (which is frequent in remote parts).

Connect the phone app to the box using the instructions on the settings page and navigate to the displayed browser address. The page will load more cleanly if the web page is saved to the home screen as this disables tabbed browsing. All box features are mirrored on the phone. In landscape views mirror the box display as closely as possible; in portrait the displays are redesigned to fit the screen.

A question window that is open on the box (such as abort stage, or a reset) also appears on the phone, and either device can answer it.

Beep assist

Beep Assist uses the to figures on the segments page as the roadbook boxes, so nothing more needs to be entered. It is switched on in settings.

Beep navigation: The box double-beeps a set distance before each roadbook box.

Beep timing: The box single-beeps at the time the car should pass each roadbook box. This reveals distance errors from wheel spin, corner cutting or a skipping sensor.

Beeps follow Total, so pressing +10, -10 or set moves them all.

The settings are:

  • Beep navigation – off/on.
  • Navigation advance – the distance in metres before the box at which the double beep sounds (100 recommended).
  • Beep timing – off/on.
  • Timing advance – the number of seconds before the box time at which the single beep sounds (0 recommended).
Beep Assist is for greek stages and is silent in italian. In settings, Beep navigation, Beep timing and their advance figures are greyed while the rally type is italian, and the choices are kept for greek.

What happens in italian instead:

  • Inside a pc the box beeps the countdown to the end tube: the navigation double beep at 5 s, a single beep at 4, 3, 2 and 1, and a shorter beep on 0. Pressing next up to 2 seconds before the 0 still sounds that beep for the row being left; pressed earlier, it is a plain skip with no beep.
  • The same countdown sounds on a navi row, to warn that next is due.
  • Every row that is not a pc also beeps once at 100 m before its end.
  • The box speaker's countdown beeps sound about 0.1 s early to cover the audio delay (an estimate, not yet measured on the Pi).

Setting rally configurations

DATE / TIME

The page shows the following.

  • Rally time (white) – the clock all stages are timed against.
  • Computer time (cyan) – the Raspberry Pi's clock.
  • Phone time – the linked phone's clock. It shows no phone when no phone is linked.
  • Offset to computer – how far rally time is ahead (+) or behind (−), for example +2.3. Beyond a minute it is shown as -11:49.2.

Setting the rally clock

  • set rally to computer time – sets the rally clock equal to the computer clock.
  • set rally to entered time – type hh:mm:ss (or hh:mm; tenths cannot be entered) in Enter rally time and then press the button. Today's date is used.
  • set computer to phone time – sets the Pi's clock from the phone and leaves the rally clock as it is. The button is greyed until a phone connects. The Pi needs its usual password-free permission to set its clock. Without it the box shows The computer clock could not be set and nothing changes.

Trimming

-0.1 and +0.1 trim the rally clock by a tenth of a second per press. Hold the button to repeat. The change is saved immediately.

CALIBRATION

Calibrating over a set distance

  1. Press zero counters. (This step can be skipped, in which case the distance since the last Total reset is used.)
  2. Drive the measured distance (from 500 m to 100,000 m).
  3. Enter the actual distance driven (not the distance the box shows) in Actual distance. It is entered in metres, or in miles when Distance units is set to miles.
  4. Choose the counter, sensor 1 or sensor 1&2. The selected counter is shown in white.
  5. Press save calibration.

The page shows the calculated distance, each sensor's count and the pulses per km in use. If the distance is out of range, or nothing was counted, pressing save calibration does nothing and no warning is given. Check that the pulses per km figure has changed.

Setting the pulses directly

If the pulses per km figure is already known, type it in Reset to and press save pulses. No driving is needed. A figure of zero or less is ignored.

Prop/Wheel RPM

The last row shows the propshaft or wheel rpm from sensor 1. Type the sensor's pulses per revolution in the small box.

SETTINGS

Each switch shows its current state lit. Changes are saved immediately.

Tone

  • Ahead/Behind Tone – switches the driver's error tone off/on.
  • Tone when behind / Tone when ahead – select type 1 or type 2 for each. Both types are silent when the error is under 0.2 s, and in the first 250 m (in italian this is counted from the moment a pc or pm starts).
    • Type 1 is a buzzer tick that speeds up with the error in 0.2 s steps, from about one tick a second at 0.2 s to about eight a second by 3 s. The tick is slightly higher when behind.
    • Type 2 is a steady tone that rises in pitch in 0.2 s steps up to 3 s. The tone is higher and harsher when behind, and lower and smoother when ahead.
  • Gauge range ± s – sets the gauge to 1, 2 or 3 seconds at each end.

System

  • Rally type – select greek, surrey or italian (see Rally types). Choosing a rally type does not change any other setting. Distance units, Speed units (kph or mph) and Measure type stay as you set them, so check them after changing type. The software version (Nero2.1) is shown above it.
  • Reaction time offset – can be set from −0.30 to +0.30 s in steps of 0.01 (default 0). A press at a point is treated as having been made that much earlier, with the car that much further back. A positive figure means the crew press late. Find your figure by comparing the box's pc times with the official results.
    • It applies to the italian tube next, the greek next speed, start now when moving at 5 kph or more, and the surrey start and finish.
    • It does not apply to autostart, ±10, set or prev.
    • The distance is moved back only for the greek next speed, the surrey start and a moving start now, and only at 5 kph or more.
    • On an italian tube press the pc clock goes back by the offset but the distance does not move. It stays on the card figure. An italian start now does the same, and only when the sector opens on a pc or pm.
  • Phone sound lead – set with − and + in steps of 10 ms, from 0 to 400 (default 100 ms). It sets how early the box tells the phone to sound an Italian countdown beep, to cover the phone's audio delay. It applies to the countdown beeps only, not the 100 m beeps. The phone shows the same figure.
  • Speed units – kph or mph, for every rally type. The setting applies to the driver display, the Italian sector card, the Segments speed column and the phone. The heading of the Segments speed column reads KPH or MPH, and a speed typed there is in these units.
  • Distance units – five keys on one line set the format and the unit.
    • The format is 0.00 (two decimals), 0.000 (three decimals) or 0,000 (whole metres).
    • The unit is km or mi.
    • Any format can be used with either unit, except that 0,000 is greyed when mi is lit.
    • A three-decimal figure drops to two decimals from 100 km or 100 miles.
    • The setting applies to the driving figures and add distance. It does not change to kilometres at 100 km.
    • The set pop-ups (Set Total, Set Navi), Distance at start, Trip history and the phone use the same unit.
    • Miles suit UK events, whose roadbooks and average speeds are in miles and mph. Choosing mi does not change the speed units, so set mph as well.
    • With mi the +10 / -10 keys read +.01 / -.01 and step 0.01 mile, and the calibration page takes its measured distance in miles. Beep assist distances stay in metres.
    • A decimal figure is cut down to its last place and is never rounded up, so it never reads ahead of the car. In km this is the 10 m (two decimals) and in miles the 0.001 mile (three decimals). This includes the Italian sector card.
    • A counter that reverse takes behind its start reads negative.
    • Typed distances are kept to the metre in km and metres, and to the nearest 0.001 mile in miles.
    • Changing between km and mi asks for confirmation first, and is refused while a stage is running. Every programmed stage keeps its figures and changes unit: a 5.000 km (5000 m) stage becomes a 5.000 mile stage. Total, Trip and the calibration are not changed. The calibration (Pulses/KM) always stays per kilometre. Changing only the format (0.00, 0.000, 0,000) changes how a distance is drawn, never the distance.
    • Italian follows this setting too. The sector card's distance columns and countdown, and the driver display's Total and Sub, read in km or whole metres to match.
    • The box itself counts in millimetres. Metres and kilometres are only how a figure is shown on screen, so a displayed figure can be up to 10 m different from the box's own count.
  • Measure type – AB,BC shows the A-B, B-C zero key on the greek and surrey navigation pages. AB,AC hides it.
  • Stage data logging – writes one file per stage with a row every second (distance, speed, ahead/behind error), from the stage start to its end or abort. If switched on mid-stage, logging starts immediately. If the file cannot be written, logging switches off without warning.
  • Sensor logging – writes the raw counter readings, many rows a second while on, so the files are much larger.

Both logs are deleted after 60 days (at program start) and can be downloaded on the phone's Set tab.

The spanner key (bottom left of the keypad) opens Setup. Under it are shown the screen update rate (fps) and the Pi's CPU temperature.

SETUP

  • Screen setup – lists each display found, with a rotate key and a touch keyboard switch for each. reset layout is also here. Force single display puts the gauge on the co-pilot screen from the next program start.
  • Bluetooth speaker setup – remember playing speaker stores the speaker that is now playing. Use connect / disconnect for it later.
  • Wi-Fi setup – there is one key per saved network: the box's own hotspot (lit when in use) or join for another network. Below them are the phone app address and QR code. When the address is opened from the phone's home screen it runs without browser bars.
  • check for software updates – closes the program and checks for an update (internet is needed).
  • settings – returns to the settings page.
